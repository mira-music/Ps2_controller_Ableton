# FX Machine texture kit — editable overlay sheets

These original, watermark-free overlay sheets are working material for the physical-panel edits. They are intentionally supplied against a black background to make individual fragments easy to isolate in Photoshop.

| File | Contents | Suggested use |
|---|---|---|
| `peeled_label_shapes.png` | Blank torn paper labels, strips, corners, fragments | Add editable label areas or paper remnants to a panel. |
| `music_stickers_sheet.png` | Original distressed music-culture graphics | Add selective personality to empty areas; use sparingly. |
| `tape_and_repair_sheet.png` | Masking tape, gaffer tape, foil patches, folded tape | Add believable repair/history details. |
| `damage_and_wear_sheet.png` | Scratches, scuffs, fingerprint marks, chipped corners, knob-wear arcs | Apply as low-opacity material wear. |

## Photoshop workflow

1. Open a copy of a master panel and drag in an overlay sheet as a new layer.
2. Use **Select → Color Range**, click the black background, and delete or mask it. This creates a transparent overlay layer.
3. Select/crop one desired fragment; keep it on its own named layer.
4. Use transform, rotation, opacity, and masking to fit the panel.
5. For subtle panel wear, start at **10–25% opacity**. Keep critical UI areas readable.
6. Save a working PSD separately, then export the edited panel as PNG at the exact native dimensions of its original master.

## Design restraint

The best result will feel like a well-used personal performance instrument—not a randomly damaged object. Keep the biggest stickers/tape away from:

- EQ knob wells and meter slot;
- the Session Navigator LCD interior;
- FX knob wells;
- live-label, value, and status areas.

No third-party logos, artist names, or copyrighted artwork are included in these source sheets.
